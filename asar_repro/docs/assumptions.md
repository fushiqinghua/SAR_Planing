# 阶段 0 的模型边界

本轮仅构造空 Leeway 实例以核验 API。没有事故地点、风流、粒子、探测观测或搜索路径输入，验收结果与随机种子无关。

| 依据 | 后续实现与验证约定 |
| --- | --- |
| [论文] Eq. (1)、(5)–(7) | 目标先运动，再削减访问单元的未探测质量。以每步探测后的剩余质量之和为有限预算目标，前缀代价按同一方式累计。 |
| [复现约定] 阶段 1 | 从 `b₀=p` 开始，起点零步免探测。每步移动到四邻格并搜索，保留未归一化的联合质量。初始总质量为 1 时取 `Pd(T)=1−Σᵥ b_T(v)`，处理论文 Eq. (2) 的括号问题。 |
| [复现约定] 阶段 2–3 | 先独立 DFS 枚举 toy 的全部合法路径，再对照 Algorithm 1 的搜索结果。Algorithm 2 的未来可达半径按距当前状态的相对步数计算。 |

## 阶段 1 的离散模型

- 顶点按行编号，从 0 起算。矩形网格只有上下左右相邻边，每条边耗费一步。允许经合法边返回已访问格，零预算只包含起点。
- 行随机矩阵的行是来源、列是去向。静止目标用恒等矩阵，平稳运动可重用一个非恒等核，时变列表的首项是 `P₁`。目标转移覆盖网格内的全部概率质量。目标运动核与搜索者的四邻边约束分别给定。
- `p` 为总质量 1 的向量；`q` 可为统一标量或每格一个值。每次访问按同一条件探测率独立削减该格质量。概率和矩阵计算采用 float64，初始总和与转移行和的绝对验证容差为 1e-12；保留原输入的浮点舍入误差。
- `survival[t]=M_t`、`g[t]=Σ_{k=1}^t M_k` 都含第 0 项。`delta_pd[t-1]` 对应第 t 次探测移除的质量。`J=g[T]` 以离散步计。每次调用只给传入的完整路径评分。

## 阶段 2 的搜索与比较

- [复现约定] Oracle 的 DFS 对每条完整路径从相同的 p 重放评分，堆搜索从各自父状态增量更新。两者共用阶段 1 的网格、运动和探测定义。Oracle 选 float64 数值最小值，并列集合相对此最终最小值取绝对容差 1e-12；算法对照与重放的验收容差均为 1e-10。
- [复现约定] 固定 h=0，队列按 (g, 入队序号) 排序。每步代价为探测后非负总质量，因此前缀 g 是其每个完整后继代价的下界。上界来自已入队的可行终点，生成时仅拒绝 g ≥ 上界的候选。首个出队终点结束搜索；持平时允许只返回一条解。比较上界时使用原始 float64 数值，以保留小于验收容差的真实数值改善。
- [复现约定] expanded 为已展开的非终点数，generated 为构造的子候选数（不含根），pruned 为入队前被上界拒绝的数量。peak_open 是待处理节点数的峰值，包括根；DFS 对应栈，堆搜索对应最小堆。runtime_s 单次计量求解调用，包含 Oracle 在叶子上的评分，额外核验、输入构造、写盘和绘图耗时单独排除。

## 阶段 3 的下界与 ε 界

- **[论文]** Algorithm 2 在每个未来时刻先传播信念，然后在放宽的可达集合内选择 `q(v)·prior(v)` 最大的一个格，削减该格质量并累加剩余总质量。Theorem 1 对这一贪心启发式提出可采纳性主张。
- **[复现约定]** 正式模式以输入状态顶点为固定中心，第 k 个未来动作使用距离 ≤ k 的所有格（包括中心），转移核使用绝对时间 d+k。模拟选择之间可以跳格；并列取最小顶点 ID。诊断模式仅将半径替换成绝对时间 d+k。
- **[下界依据]** 未探测质量非负，故 zero ≤ 最优余下代价。设当前质量 M，转移守恒，单次探测最多移除 q_max·M。第 k 步残余质量至少为 M·(1−q_max)^k，求和至剩余预算即得 mass_lb。q_max 为 0 时得到 R·M，为 1 时得到 0；终点余下代价为 0。
- **[搜索保证]** 对可采纳 h、非负代价和 ε≥1，在最优路径任一前缀上有 g+εh ≤ εJ*。若该前缀因已有完整解而被剪枝，则该完整解已满足 ε 界；否则，在找到最优终点前，堆中仍有这样的前缀。首个出队终点因此满足 J≤εJ*。zero 在任意有限合法 ε 下保持一致代价排序。该推理应用于完成搜索的理想离散模型，数值核验采用 float64 与 1e-10 绝对容差。
- **[数值证据]** Oracle 限定真实前缀、穷举完整后缀，从原始 t=0 重放最优完整路径，只将前缀后的 M 累加为 h_exact。paper_greedy 的每次搜索均标记为论文算法复现；静态 toy 中通过逐前缀检查，只作为该实例的有限证据。动态反例的含义限于一般时变模型，不推断论文四个海洋场景的具体结果。

## 阶段 4 的 toy 与对照方法

- **[论文]** Fig. 2 展示静态目标、完美传感器、30 步预算的路径与信念图。具体先验矩阵未公开。**[复现约定]** 按论文思想重建两座高斯峰；YAML 配置峰中心、标准差、振幅。seed=41 控制中心扰动，网格上先叠加两个核，再按总和归一化。两个场景共享这个初始分布，均从零基行列 (3,0) 出发。
- 静态场景采用恒等运动和 q=1；新增动态场景采用 q=0.78，第 1–15 步向东偏移，第 16–30 步向南偏移。运动仅在原格与四邻格间分配概率，越过边界的份额留在原格。该模型是合成的时变随机游走。
- 动态蛇形水平扫描至边界，在上下相邻行中，选择下一步预测可探测质量总和最大的行，竖移一步后反向扫描；并列取较小行号。邻居贪心每步只在相邻格中最大化 q·prior，并列取较小顶点编号。A^SAR 沿用阶段 3 的 paper_greedy、ε=1.10。三种方法输出完整路径，统一由 score_path 评分和记录 b_t。
- 顺序实验先后交换向东、向北的两段等长往返（各 6 步），在第 12 步同回起点，再执行同一段 18 步路径。静态 q=1 时，两条路线自第 12 步起的逐格信念完全相同，J 的差来自前 12 步。

## 阶段 5 的物理输入与质量记账

- [复现约定] Lake Ontario 配置沿用表 I 的事故点、CSP、UTC 时刻、PIW-2、0.1 海里栅格和 49 步。选用 500 粒子、seed=41、Leeway 撒布参数 radius=100 m。假定恒风 (4,0) m/s、恒流 (0.15,0.05) m/s、全域水面；步长以 185.2 m / 20 m/s 映射为 9.26 s。图中海岸线与真实风流均未建模。
- [复现约定] 源时间轴从事故时刻开始，每 30 s 输出一次；最后一步向上覆盖规划结束时刻。只对覆盖范围内的 UTC 时刻进行线性纬度、最短经度弧插值。状态或掩膜切换时，将不确定区间留在不可搜索类别；原始时刻直接取样。源帧留一半的误差用 WGS84 测地距离计算，衡量时间重采样误差，不能用于估计真实海上定位精度。
- CSP 为局部方位等距投影原点。水域格按行优先、行 0 在北侧，西/南边界含、东/北边界不含。编号 289 至 292 依次为陆地/搁浅、域外、其他失活、未知。活动粒子可以从地图外重入；标记 stranded 或 outside 的终止状态在原始后续空值上延续。其他已知失活状态优先按状态归类，活动粒子按掩膜和位置归类。终止后缺失的地理坐标仍保留为 NaN。
- CST 先验是原始第 120 帧的粒子分格。事故至 CST 不执行探测。各 ID 的初始权重为 1/500；每步只将指定水域格中粒子的权重乘以 1−q。全体粒子的残余质量包含四类特殊格。审计使用穿过 CSP 的固定同行往返路径及 q=0.78，该路径仅用于核验。

## 阶段 6 的粒子状态与预算

- 搜索预算 T=49，固定输入是同一套 seed=41 的 500 条轨迹。每条分支拥有独立的 float64 未探测权重。时间步只改变 ID 对应的格号，探测只作用于当步访问水域格内的 ID。总质量包含不可搜索的特殊格。
- Algorithm 2 在未来绝对时刻按当前模拟权重做加权 bincount，在相对可达半径内选择探测收益最大格，再削减该格粒子权重。同位置同深度的不同信念仍是不同状态。可缓存的是格点距离、可达集合和各帧的粒子索引。
- 比较中八次搜索共享同一条从 CSP 出发的可行初始路线，其 J 经评分器复算；各 ε 互不传递结果。可重复排序沿用阶段 2/3 的 (f, 入队序号)。所有 paper_greedy 返回的 theory_certified 均为 false。
- 时间预算是协作式 wall clock 限制，按节点及启发值计算前后检查。扩展上限限制非终点展开次数，OPEN 上限限制实际入堆节点数。达到上限且下一操作需要超额时返回 budget_exceeded；max_seconds 单独标记 timed_out。已有完整路径时记录其来源及分数。独立进程的峰值工作集包括解释器、运行库、轨迹、索引和堆；计时仅含搜索及初始路径评分。
