# 预声明判断与停止规则

当前状态：**`not_run`**。以下通过状态必须由本地实际验证与全部预定任务生成。实现准备、语法解析和上一批结果不填写为本批通过。

## 1. 先检查正确性与完整性

出现以下任一情况时停止后续正式任务：输入／源码指纹不一致、旧评分桥接失败、测试失败或跳过、轨迹非法、漏观测或重复观测、实际时长未覆盖 H、地速或预算异常、原始记录缺失、独立 oracle 不一致、任何求解错误被初始路线掩盖。

A 阶段全部 48 项任务须有效。全部独立 DFS 在预算内完成，给出完整枚举结果；其返回路线经公共模型重放后 J/Pd 相符。对应搜索候选不得优于已枚举最优值超过 1e−8。每个传感器下 J₈*≤J₄*+1e−8；违反时先排查模型／枚举，不进入真实场景。

此外，预定 `diagonal_intercept` 用例须在至少一个预定传感器代理下满足 J₈*<J₄*−1e−8，给出同速对角截获的严格数值见证。无见证时 A 不通过；保留失败，先检查机制或实现，不按结果重新选择用例。

正常按预算停止且保存预算内可行解，不等于程序错误，也不等于已证最优。迟于截止时刻才完成评分的改善只能保留为晚到记录，不能计入主表。

## 2. 每个预算分别判断主要质量收益

对每个预算 B∈{B5,B30}、场景 s、传感器 f，定义：

\[
G_{B,s,f}=\frac{\operatorname{median}J_{4,B,s,f}-\operatorname{median}J_{8,B,s,f}}
{\operatorname{median}J_{4,B,s,f}}.
\]

G>0 表示八邻接更好。中位数来自该完整分组的三次预定计时重复；它们不是三份独立环境。原始值、范围、有效数量和失败必须同时报告。

主要模型 f=`heading_square` 的 Q 门槛为：

1. 至少一个主场景 G≥0.005，即 J 中位数改善至少 0.5%。
2. 另一个主场景不得相对退化超过 1e−8，即 G≥−1e−8。
3. 该预算两个场景、两种邻接的全部预定运行有效，且来自同一冻结版本。

定义改善场景集合：

\[
S_B^+=\{s:G_{B,s,\mathrm{heading}}\ge0.005\}.
\]

仅保持共同初始路线不变不算改善；八邻接只优于旧 PT 或旧评分下的历史数值不算通过。比较必须是同预算、同代理传感器下本批重新评分的四邻接对照。

## 3. 同预算传感器敏感性检查

只有与主要模型**相同预算**的 `axis_square` 结果可以参与该预算的敏感性判定。两项都需要满足：

1. 至少一个 s∈S_B⁺ 在 axis_square 下仍有严格正收益，G_{B,s,axis}>1e−8。
2. axis_square 的两个主场景均不退化超过 0.5%，即 G_{B,s,axis}≥−0.005。

0.5% 是事前指定的工程容差，不是统计显著性阈值。敏感性通过不表示两个代理已覆盖真实相机不确定性，更不等于设备标定或实飞验证。

结果状态：

| 条件 | 状态与解释 |
|---|---|
| 任一必要任务缺失或无效 | `incomplete_or_invalid`；不评价门槛通过 |
| B5 的 heading_square Q 未通过 | `screen_not_passed` |
| B5 的 heading_square Q 通过，axis 敏感性未通过 | `sensor_sensitive`；收益依赖当前覆盖假设，不称稳健 |
| B5 的 Q 与同预算敏感性均通过 | `screen_passed_pending_holdout` |
| B30 的 heading_square Q 未通过 | `longer_budget_screen_not_passed` |
| B30 的 heading_square Q 通过，axis 敏感性未通过 | `longer_budget_sensor_sensitive` |
| B30 的 Q 与同预算敏感性均通过 | `longer_budget_signal_pending_followup`；记录为30秒的独立正信号，不回写 B5 |

即使仅 B30 有收益，也只支持未来为30秒应用情境另立验证协议。B5 和 B30 不能择优合并成一项主结论。

## 4. Pd、计算时间与资源解释

J 是本批主要优化目标。Pd 来自同一条路线并单列；J 改善而 Pd 下降时必须明确给出这一权衡。分组的中位 J 与中位 Pd 未必来自同一次运行，不拼接为实际路线。

主实验给定相同算法预算，分别报告算法墙钟、进程墙钟、CPU、展开／生成节点、采样峰值 RSS、实际超额和截止前最佳解。总飞行时长 H 与算法计算预算是不同概念。

本批没有把旧模型 J 作为 time-to-target。新模型分数及传感器规则可能改变；若结果之后定义某个达到目标，只能标为事后描述，不能用于本批预声明通过判定。仅内存降低、展开减少或对角动作更多不构成质量胜出。

原始高质量初始路线的离线生成成本统一不计；因此不能将本批计算时间声称为从零产生完整方案的端到端时间。

## 5. 收到结果后的行动

| 观察 | 下一步 |
|---|---|
| B5 主模型与敏感性均通过 | 固定实现和参数，设计独立漂移档案验证；尚不宣称普遍优势 |
| 只在 B30 通过 | 保留30秒适用信号，明确计算预算条件；不追认5秒优势 |
| 仅 heading_square 改善 | 检查覆盖朝向与航迹的耦合，先取得传感器依据，再决定是否继续 |
| 小图八邻接有严格收益，真实档案无收益 | 报告几何机制见证与真实档案负结果，检查真实粒子结构；不筛选只利于八邻接的场景 |
| 八邻接因搜索更难而劣于四邻接 | 保留可行域潜力与有限预算求解差距的区别；只有明确瓶颈证据才设计求解改进 |
| 四／八邻接都只保留初始路线 | 本批未找到可利用收益，按协议结束；不能由此证明两者最优值相同 |
| 模型、覆盖、时钟或评分错误 | 保留失败，修复后新目录、重新验证和冻结；旧结果不归到新实现 |

本批没有自动300秒扩展或独立档案阶段。正确性门槛通过后，B5 与 B30 都按预定矩阵完成；质量门槛未通过时，仍在本批固定范围内结束，不因已经投入实现而继续放大预算。

## 6. 不得推出的结论

- 八邻接允许更多动作，不等于新求解器在同一问题上优于 baseline。
- 相同地速的局部对角转场节省29.3%，不等于总 J 或 Pd 同比例改善。
- 一个模型内 J 降低，不等于具体相机、真实飞控或实飞任务已受益。
- 小图枚举闭合，不等于真实500粒子场景已证近最优。
- 三次同档案计时重复，不等于独立泛化验证。
- 两个几何代理结果一致，不等于扫幅、实际视场和观测概率已经标定。
- 旧四邻接 STDC 的证明与数值审计，不自动适用于八邻接和变时长航段。
