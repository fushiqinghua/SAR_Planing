# 预声明判定与停止规则

状态：`prepared_not_run`。本文件中的通过条件是研究投入门槛，不是实验结果，也不是预期提升的承诺。

## 1. 先检查实验是否有效

只有全部 24 个登记任务完整且通过审计，才允许判定方法表现。失败、缺失、输入变化、非登记任务或被覆盖的原始记录不能按平局处理，也不能删除后只汇总剩余任务。

有效性要求包括：

- 四个实例、两个方法、三次重复及任务顺序与冻结协议一致。
- 代码、环境、配置、输入与共同 S30 路线保持冻结身份。
- 同一实例的 C0/C1 使用同一动态粒子档案、航速、H、q、覆盖与观测时钟。
- 每个被接纳候选在其阶段截止、总截止与接续锚点之前完成必要原评分审计。
- C1 的已执行/承诺前缀不可更改，权重和绝对时间连续，完整路线按原物理评分重放一致。
- 阶段耗时、超时返回、缺少锚点、无改善、内存停止和异常均保留。

截止之后返回的函数可有迟到诊断，但不得因此获得额外可接纳解。实际耗时与候选可接纳时间分开记录。出现实验语义错误时，先保留失败；修复实现需新版本、新输出目录和重新冻结，不把修复后的运行填进原失败记录。

## 2. 配对汇总规则

对每个实例 s、每个方法 m，先取三次运行的最终 J 中位数：

\[
\widetilde J_m(s)=\operatorname{median}_{r=0,1,2}J_{m,r}(s),\qquad
G(s)=\frac{\widetilde J_{C0}(s)-\widetilde J_{C1}(s)}{\widetilde J_{C0}(s)}.
\]

G > 0 表示 C1 的 J 更低。终点 Pd 必须取同一个 J 中位代表运行的值，不允许分别挑选最好 J 和最好 Pd 拼成一条不存在的路线。并列时使用固定重复序号规则。原始三次 J、Pd、范围、路线和耗时全部保留。

两次“算法调用阶段”不是两个实例；三次“计时重复”也不是三个环境样本。不在这四个已见实例上声明独立泛化或总体统计显著性。

## 3. 主要质量筛选

同时满足以下条件，才认为本轮提供值得继续研究的质量信号：

1. 24 项全部完整有效。
2. 至少 3/4 实例满足 G(s) ≥ 0.005，即 J 中位数改善至少 0.5%。
3. Lake 和 Hudson 均至少有一个实例满足上述改善门槛。
4. 所有实例 G(s) ≥ −1e−8；这个相对容差只用于排除数值噪声。
5. 各实例的代表终点 Pd 差值 ΔPd = Pd(C1) − Pd(C0) 不低于 −0.005，即不损失超过 0.5 个百分点。

0.5% 是工程投入门槛，不是最小统计可检出差异。0.5 个百分点的 Pd 规则是阻止继续推广的次要检查，不改变本轮求解器的 J-only 优化目标，也不等价于旧 `completion_pd_guard` 约束。

如果 J 条件满足但 Pd 检查未通过，应写清楚“J 质量信号存在，但终点发现概率权衡未通过”。不能说两个指标都提升，也不能将本轮改为 Pd 约束后继续使用同一协议。

## 4. 时间与资源指标的解释

本轮主要问题是相同总可接纳预算下的最终 J，而非证明加速。两组总上限一致，但提前结束、未触发或没有可用锚点会使实际消耗不同。

必须报告：

- 实际算法墙钟、CPU、进程墙钟、RSS 与 OPEN 停止情况。
- C1 每个阶段的请求时间、锚点时间、实际准备完成时刻、接纳状态、前后 J/Pd、累计计算支出和未用预算。
- 迟到候选和函数返回越界；不能将其隐去或从耗时中扣掉。
- 原任务各观测时刻的剩余质量 S(t) 与累计发现概率 1−S(t)。

不能用“展开更少”“缓存命中更多”“单次调用更短”代替路线质量证据。也不能用 C1 第五次调用的 6 s 与 C0 整次 30 s 相比来宣称五倍加速。

本轮不预声明 time-to-target 加速门槛。若以后研究同质量效率，需要固定质量目标、完整候选首次可用时刻和删失规则，另行登记；不在看过这轮结果后选择有利目标。

## 5. 停止与下一阶段

| 结果 | 允许的解释 | 下一步 |
| --- | --- | --- |
| 有效性检查失败 | 还没有可比较的结果 | 保留记录，修复后新版本、新目录、新冻结 |
| 全部质量条件和 Pd 检查通过 | 已见实例上的有限预算滚动规划信号 | 冻结方法，再设计独立日期/粒子验证 |
| 少量实例改善，未达整体门槛 | 存在有限见证，尚无稳定工程收益 | 记录机制和负结果，本配置停止 |
| J 改善但 Pd 损失超门槛 | 目标权衡明显 | 停止推广，不改写成联合提升 |
| 只有额外算力、时间重置、漏计迟到或弱对照时改善 | 无法归因于所提机制 | 本轮不通过 |
| 多数结果相同或退化 | 固定预测下这一滚动配置没有显示价值 | 不无限扫描间隔；只有明确新反馈/误差处理机会才另立协议 |

没有胜出不等于当前八邻接已全局最优，也不排除所有滚动规划。通过也不证明任意海况、实机覆盖或 ε 最优。
