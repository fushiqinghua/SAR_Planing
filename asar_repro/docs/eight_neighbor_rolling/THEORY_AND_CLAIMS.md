# 模型、数学解释与论文表述边界

状态：`prepared_not_run`。以下论述解释本轮机制与评价口径，不给出尚未运行的性能结论。

## 1. 本轮输入已经是动态预测

冻结粒子档案记录稳定粒子 ID i 在整个任务各观测时刻 t_k 的位置 x_i(t_k)。某条搜索前缀之后，粒子保留未探测联合概率质量 w_i。对应时刻网格 c 的质量是：

\[
b_k^{-}(c)=\sum_i w_i^{k-1}\,\mathbf 1\{x_i(t_k)\in c\}.
\]

粒子位置随风流预测变化，粒子权重随此前搜索覆盖变化。两者都已进入原物理状态推进和搜索引导。预计算整个预测序列不等于冻结搜索初始密度图，也不等于知道真实目标的未来位置。

代码证据：`physical_model.py::observation_mask` 读取 `positions_xy[tick]`；`physical_search.py::_CoarseCellGuide` 为各未来 tick 构造粒子网格映射；`physical_accel.py::remaining_cost` 用该 tick 的映射与当前剩余权重聚合网格质量。正式主搜索和贪心补全均调用动态状态推进。

## 2. 固定预测下，单纯重复预测不创造信息

考虑本轮有限时域、单目标搜索问题，并假设：

- 运动预测、传感器模型与可行动作模型固定；
- 可继续执行的观测只有“至今未发现”；发现目标后任务终止；
- 没有外部目标线索、风流更新、执行偏差或其他非终止观测；
- 比较时可使用的时间、动作和目标函数相同。

对任意确定性反馈策略，沿着持续未发现的历史递推其动作，将得到唯一的一条未终止路径。该策略在未终止时所用的概率状态可以沿路径离线计算，所得路径具有相同的发现时间分布与目标值。因此，在这些假设下，最优反馈策略不会仅因把同一递推放到执行期间就获得额外信息优势。随机化策略的期望值是各确定性策略期望值的混合，也不会小于其中的最小值。

这是本协议条件下的模型论证，不是对一般 POMDP 的结论。当出现非终止测量、环境更新、模型参数校正、多目标任务或未知执行状态时，上述条件不再完整。

## 3. 为什么有限预算仍有研究空间

现有求解器不是精确最优求解器。它在有限时间和内存内保留最好的完整路线。C1 把一部分计算留到前缀已经执行/承诺之后，只搜索这个前缀允许的后缀。

这可能减少对不会执行的分支投入，也可能因过早承诺而失去更优的前段选择。它可能改善 J，也可能退化。其性能必须由同总预算实验决定。

两组理论上可表达的完整飞行路线仍来自同一八邻接模型；C1 新增的是求解日程与不可回改前缀，并没有扩大动作集合。不能援引第一项四/八邻接集合包含关系来证明 C1 必优于 C0。

C1 每次都优化至原 H 的完整剩余路线；不将短窗口内的局部发现量当成新的主目标。此前的离线局部修复可以改写候选路径的未执行前缀；本轮则显式禁止改写已经执行或为计算延迟承诺的路径。这是必须在实现与账本中保留的区别。

## 4. 原 J 与 Pd 的保持

设 S_k 为完成第 k 次观测后尚未探测到目标的联合概率质量。本轮继续使用原评分：

\[
J=\sum_{k=1}^{K}S_k,\qquad P_d(H)=1-S_K.
\]

J 以原观测序列为单位，不直接改称秒。对同一实例，观测间隔固定，因此可作原有方法的直接配对比较；不同实例原始 J 不宜直接混合平均代替相对改善。

从已执行前缀重新定根时，保留累计 J、绝对观测 tick、粒子未探测质量及物理位置。前缀之后的优化比较共享同一个已付成本；完整报告仍需合并整条路线，按原观测轴重放。

可以为概率推理构造条件于“尚未发现”的归一化分布，但正式评分不能将每段权重重新归一化后再拼接 J/Pd，也不能把域外质量归一化到域内。本轮直接携带原联合质量以减少语义歧义。

较小的 J 不保证较大的终点 Pd。两者分别报告，Pd 的 0.5 个百分点推广检查不改变求解目标。

## 5. 时间与因果性

时间账本包含两个不同的时钟：

- **任务物理时钟**：无人机与目标的位置随这个时钟推进，任务结束于固定 H。
- **算法计算时钟**：本地实测的准备、搜索、审计和接纳耗时，累计受同一 30 s 上限约束。

C0 的一次规划被安排在 CST 前；C1 的首槽也在 CST 前，其他槽在虚拟执行期间发生。两组都使用相同的预计算信息。C1 后续调用期间沿当前路线飞往提前承诺的锚点，不能在结果准备完成后修改已经发生的覆盖。

锚点选取使用事先固定的槽额度与余量；是否按时完成则使用实际耗时判断，不能事后根据一个有利结果把锚点挪得更早。迟到结果只作为诊断保留。

在线求解从未来接续锚点定根时，预先递推了承诺前缀上的“持续未发现”权重。这是“若任务尚未终止并抵达锚点”的条件分支，不是提前读取真实传感器结果。若前缀执行中已发现目标，任务已结束，锚点之后的计划不再执行；完整原评分已经计入前缀的发现概率。

当前 H2 强迫场是历史重建，不是已验证可按真实发布时间在线获得的预报流。不能将本轮描述为“实时候选预报更新实验”。如果以后研究反馈，必须另行记录信息发布时间和规划器可见内容。

## 6. 若本轮通过，可支持与不可支持的表述

可以据完整结果支持：在指定四个已见档案、固定物理模型和总预算下，某个固定滚动配置相对当前一次性八邻接方法获得了配对 J 改善，并报告对应 Pd 与计算代价。

不能据此直接支持：

- 首次考虑搜索期间目标漂移，或首次使用动态粒子概率图；
- 新信息驱动的闭环纠偏、真实在线预报性能或实机收益；
- 任意环境下稳定胜出、全局最优或 ε 最优；
- 仅凭“滚动”“概率引导”等通用概念确立方法新颖性；
- 总飞行距离必然缩短，或两项指标必然同步改善。

后续论文贡献需要落实到具体的重规划/预算/后验处理机制，并与相近方法比较。独立数据验证与新颖性判断是后续门槛。

## 7. 相关原始研究

- [Mugford 与 Gammell，A^SAR](https://arxiv.org/html/2511.10792v2)：原方法已有目标运动、未发现质量更新和未来时刻引导；论文结尾把 anytime planning/replanning 列为后续工作。
- [Riehl、Collins 与 Hespanha，Cooperative Graph-Based Model Predictive Search](https://web.ece.ucsb.edu/~hespanha/published/CGBMPS-Technical-Report-Sep07.pdf)：概率位置采样与滚动搜索已有先例，其任务设置和目标并不等同本轮。
- [Messmer 与 Zell，Evaluating UAV Path Planning Algorithms for Realistic Maritime Search and Rescue Missions](https://arxiv.org/html/2402.01494v2)：海上 UAV 的动态粒子、负观测与局部规划相关先例。

上述研究用于界定已有内容，不把不同平台、目标函数或仿真条件下的性能数字移植为本项目预期收益。
