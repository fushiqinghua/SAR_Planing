# 严格状态等价的数学依据与声明范围

状态：`prepared_not_run`。本文件给出本轮机制的条件、证明与实验边界，不提供尚未执行的性能结论。

## 1. 等价的是未来物理状态

当前固定模型下，非终止搜索状态可写为：

\[
s=(v,t,k,\mathbf x,\mathbf w,J),
\]

其中 v 为当前完整航点，t 为绝对物理时间，k 为已完成观测 tick，\(\mathbf x\) 为实际位置，\(\mathbf w\) 为稳定粒子 ID 顺序下未归一化的未发现质量，J 为此前观测累积代价。未来粒子位置、探测概率 q、覆盖几何和任务终点属于同一个冻结问题。

实现仅为非终止状态建立索引，严格键还包含所属问题身份，以及位置／权重数组的 dtype、shape 和精确字节。t 使用 `float.hex()` 的精确浮点表示。不按小数位取整，不把相同坐标或相同概率总质量视为相同粒子状态。hash 用于加速键查找，实际相等仍由键内容和完整 bytes 判断。

当前模型下一条边的观测方向由该条边决定，没有依赖上一条边的转弯可行性或代价。历史距离与对角距离属于报告量，不是独立剩余能量约束。若未来引入转弯半径、加速度、朝向连续、剩余能源、返航状态或其他历史约束，当前键的充分性必须重新审查并扩展。

## 2. 精确等价状态的支配命题

设 A、B 属于同一冻结问题，具有相同 v、t、k、实际位置与逐粒子权重，且：

\[
J_A\le J_B.
\]

对任意从该共同状态到原任务终点的相同合法后缀 u，未来每个观测时刻的无人机位置、粒子位置和覆盖事件一致。因起始权重也相同，按原探测递推得到的所有未来权重和生存质量相同。记共同的未来代价为 C(u)，则：

\[
J(A\oplus u)=J_A+C(u)\le J_B+C(u)=J(B\oplus u),
\]

\[
P_d(A\oplus u)=P_d(B\oplus u).
\]

因此，只要保留 A 的可行后续扩展机会，B 不可能产生比 A 更好的完整 J 或更高的终点 Pd。保存较低 J 代表是安全的局部支配选择。

该命题没有要求两条历史路径相同；也不意味着它们此前各时刻的探测曲线相同。输出完整路线必须保留获选代表自己的前缀、survival 和累计代价，不能把不同路径的报告量拼接。

## 3. 实现该命题时必须遵守的条件

1. **更低 J 必须重新参与搜索。** 同键更优代表出现后更新索引并允许重新展开；不能因为同键曾经 CLOSED 就永远拒绝。
2. **旧堆条目按当前代表检查。** 只有已登记同键存在严格更低 J 时，旧的较差条目才能被跳过。相同 J 的保留代表仍有继续搜索机会。
3. **容量不能变成未经证明的剪枝。** 达到 16,384 条或 64 MiB payload 时只停止新增索引键，未登记状态继续原搜索；已有键仍可更新。
4. **每阶段独立。** C1_M 的每个前缀重规划调用独立建表，不用不同承诺前缀或不同问题的代表作剪枝。
5. **完整候选按原模型验证。** 等价证明不替代完整路径重放、预算截止和在线因果检查。
6. **不合并终止部分边。** 本轮索引只处理可扩展的非终止状态；终端 child 生成次数与本机制机会分母分开。

索引可能漏掉接近相同或容量外的等价状态，这影响效率而不使合并更激进。`time.hex()` 的精确比较也可能因为浮点累加顺序不同而漏合并，本轮接受这种保守性，不引入未经证明的时间容差。

## 4. 可以推广、但本轮不实现的边界

若未来状态的几何／时间和可行动作一致，并且逐粒子质量满足：

\[
\mathbf w_A\le\mathbf w_B\quad\text{逐分量},\qquad J_A\le J_B,
\]

则在同一后缀下，每个粒子的未来质量都乘以相同的非负探测因子，因此保持逐分量关系；从而未来 J 不更高，终点 Pd 不更低。这提供一个更一般的支配关系。

本轮只实现权重精确相等。逐分量支配的索引维护、查询成本和数值语义需要另行设计；不能将较小的总质量、某个聚合网格质量或抽样判断代替逐分量条件。

## 5. 安全合并不等于定时结果必然改善

上述证明针对保留下来的后缀解空间。有限墙钟下，索引开销、堆顺序、更低 J 的重开，以及按展开次数触发的完整补全，都可能改变哪条路线在截止前被找到。因此 C0_M/C1_M 仍需与各自原方法重新同预算比较。

本轮没有给出新的全局下界、最优性 gap 或 ε 证书。`guide_weight=1.04` 继续是排序设置。状态索引容量有限、运行被时间截断，也不能把空局部表或局部命中率解释为全局穷尽。

## 6. Lake 早平台的正确解释

早期达到最终 J 只说明该次运行很早找到该 incumbent；未证明剩余搜索空间不能改进。终点 Pd 较高也不能单独限制更早发现的潜力，因为：

\[
J=\sum_{k=1}^{K}S_k,\qquad P_d(H)=1-S_K.
\]

即使终点质量相同，中途更早降低 S 仍可降低 J。当前 Lake 大量末端展开支持“有必要测量冗余”的研究动机，但 terminal 事件数量、非终止展开位置分布、严格等价状态数量是三个不同统计量。

如果有对完整原问题有效的下界 L 和可行路线 U，才能利用 \(L\le J^*\le U\) 限制改进空间。本轮不把 guide、固定前缀子问题的界或抽样最好解冒充全局 L。

## 7. 相关研究与新颖性范围

- [Mugford 与 Gammell，A^SAR，arXiv v2，2026-02-27](https://arxiv.org/html/2511.10792v2)：原问题已包含目标运动和负观测质量更新；结尾列出 anytime planning/replanning 作为后续研究。本轮不以首次动态预测为贡献。
- [Hansen 与 Zhou，Anytime Heuristic Search，JAIR 28，2007](https://arxiv.org/pdf/1110.2737)：区分搜索排序、当前可行解和可采纳下界；图搜索中更优状态成本需要正确更新和重开。该论文有助于界定“找到好解”与“证明最优”的差别。
- [Likhachev、Gordon 与 Thrun，ARA*，NeurIPS 2003](https://papers.neurips.cc/paper_files/paper/2003/file/ee8fe9093fbbb687bef15a38facc44d2-Paper.pdf)：跨改进阶段复用搜索努力是已有研究主题，具体界限依赖其算法条件。本轮不直接套用 ARA* 的保证。

等价状态索引、transposition table 和支配剪枝属于已有搜索思想。论文贡献如要成立，应落实到动态粒子物理状态的充分性、严格等价实现、执行前缀约束、预算计费和受控结果，而不能只以增加一个哈希表命名创新。

四个已见实例上的正结果也只是继续投入的依据。主要净滚动比较、独立日期验证和与相关方法的比较仍不可省略。
