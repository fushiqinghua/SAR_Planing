# P1 事先固定的计时稳健性门槛

本规则在任何 P1 正式运行之前提交，不根据试验结果回改。

## 正确性

48/48 任务完整、源码和原历史 Lazy protocol 与输入文件 SHA256 锁定、专项及全量测试均通过；独立物理 replay 的 J/Pd/survival 与原评分一致。每项实际算法时间不超过30秒；失败或提前结束的原始记录必须保留。

## Hudson 4101：同算法波动对照

原 S30 J=28.724588352、历史优质路线目标 J=28.448979882240007。C0_A 和 C0_B 完全同一个 C0 算法，共24次，Lazy12次。

- 坏跑：J>=28.724588352-1e-8（未超过共同 S30）。
- 高质量命中：J<=28.448979882240007+1e-8。
- 非劣**工程筛选**：Lazy 的中位 J <= 合并 C0 的中位 J+1e-8；Lazy J 的 nearest-rank p90 <= 合并 C0 p90+1e-8；Lazy 坏跑率 <= 合并 C0 坏跑率+1/12（即至多一个额外重复的容许差）。

同时必须报告 C0_A/B 本身的 J 分布、坏跑和达标率、首次严格 search 改善时刻、Pd、RSS、CPU 与最差质量。若所有方法大多未达到目标，应报告证据不足，不能当成泛化成功。不是统计显著性/非劣性检验。

## Hudson 4201：正向收益保持

Lazy 6 次中至少 5 次 J<=58.5220872+1e-8，且6次的 Pd 中位>=0.090948-1e-8。每次与同区块 C0 记录相对收益。任一明显退化、内存上限或错误均保留证据。

P1 同时通过 4101、4201 才标记 timing_screen_passed。通过后**冻结候选不再调参**，进入新的 H3 forcing 日期；未通过则分析计时和逻辑错误，不以改变阈值求通过。

## P2/H3 单独冻结的日期级标准

对新日期 d、粒子 seed s，双方各3次 J 中位，计算 gamma(d,s)=(J_C0-J_Lazy)/J_C0；日期值取两个 seed 的中位。

- 至少 4/6 日期 gamma>=0.1%，两地区各至少一个；
- 不得出现日期 gamma<-0.5%，任何 seed gamma<-1.0%；
- 终点 Pd 若在任一 seed 比同路对照下降超过0.5个百分点，必须标记终点风险，不能称 J/Pd 双指标稳健；另报达到0.5%的日期数、改进中位数、最差样本；
- 日期为外推单位，seeds和计时重复均嵌套其内，不能把72次求解当作72份独立天气。

这些是预登记工程筛选，不构成全局最优或统计显著性证明。
