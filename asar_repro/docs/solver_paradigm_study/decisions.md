# 预声明决策规则

**当前状态：`not_run`。所有通过／未通过栏必须由本地完整原始记录生成。** 本文件不改变上一批 STDC 的停止结论。

## 1. 三个层次分开判定

| 层次 | 问题 | 所需证据 |
| --- | --- | --- |
| 机制见证 | 有没有真正不同且更好的路线？ | 完整合法路径、原评分重放、预算内完成；相对历史参考严格降低 J |
| 工程筛选 | 同预算是否有值得继续投入的收益？ | 完整重复、与同批廉价强对照比较、预声明质量或时间门槛 |
| 外推验证 | 收益能否在独立实例上保持？ | 冻结的新档案、配对统计和完整失败记录 |

一个幸运 seed 不能替代工程筛选；重复计时不能替代独立实例。数学下界更紧也不自动意味着更快或找到更好的路线。

## 2. 严格改善的机制见证

对同一真实档案，要求 \(J_{ref}-J_{candidate}>10^{-8}\)，其中候选与参考均按原 `score_path` 重放。报告绝对差值、相对差值、Pd 变化、首次路线分歧时刻、完整路线和完成时间。

`1e-8` 是排除浮点噪声的绝对 J 门槛，不是有实际意义的收益门槛。相对 PT 改善而未突破参考，不记作突破现有最好结果。若 J 改善而 Pd 降低，应如实报告，不把两项指标都标成提升。

## 3. 主要工程筛选：B5

记某场景在同批 5 秒任务下：

\[
J_{cheap}=\min(\operatorname{median}J_{zero},\operatorname{median}J_{mass}),\qquad
G=(J_{cheap}-\operatorname{median}J_{new})/J_{cheap}.
\]

### Q：质量门槛

- ILS 或 CEM 在至少一个主要场景的 G ≥ 0.005，即 J 中位数改善至少 0.5%。
- 同一方法在另一个主要场景相对 \(J_{cheap}\) 的退化不得超过 \(10^{-8}\) 的相对容差。
- 两个场景的全部预定随机 seed 和廉价对照重复均有效。缺测、语义错误或被删除的运行不能视为通过。
- 同时报告五个随机 seed 的原值、范围、胜出数及 Pd；中位数并不等于跨实例统计证明。

### T：同质量时间门槛

预定目标为 \(J\le1.001J_{ref}\)，以首次在预算内完成原评分的时刻判断。

- 两个主要场景均要求新方法的中位 time-to-target ≤ zero 和 mass 各自中位数的 80%，即相对每个廉价对照至少快 20%。
- 新方法全部五个 seed、各廉价对照全部三次重复都达到目标，才能使用这条完整样本中位数规则；含删失时本门槛不通过，另报达到率和生存曲线信息。
- 新方法的最终 J 中位数在两个主要场景均不得相对 \(J_{cheap}\) 退化超过 \(10^{-8}\)。
- “展开更少”“每秒候选更多”是成本解释，不替代 time-to-target。

Q 或 T 任一通过，记为 `screen_passed_pending_holdout`。两个均未通过时，记为 `screen_not_passed`。不能因为接近门槛、单个 seed 很好，或 B30 比较有利，就改写 B5 的通过状态。

B30 按相同定义另列描述性比较，明确标为 30 秒结果。如果它提供有价值的信号，可以触发下节的有限诊断或下一份独立协议，但不能回写 B5。

## 4. 300 秒延长诊断触发规则

候选只限 ILS/CEM 与 Lake/Hudson 的组合；配置和前两个随机 seed 在正式运行前已冻结。满足下列任一项才触发：

1. 按第 3 节同样的完整两主要场景规则，该方法在 B30 通过质量或同质量时间筛选；该场景不得相对廉价强对照退化；或
2. 该方法在该场景的 B30 中，至少 2/5 个 seed 独立产生预算内严格参考改善（各自差值 > 1e-8）。

必须先生成带原始 run ID 的 gate 记录，再运行 300 秒任务。最多 4 个方法—场景组合、每组合 2 个 seed，即最多 8 次／2400 秒算法预算。门槛未触发时明确写 `not_triggered`，不能因“已经做了很多工作”而自动运行。

延长诊断使用原方法参数；若实现和参数改变，须另起协议、重新做 P0 与必要的 B5/B30 比较。300 秒结果用于解释改善是否随预算累积、是否早停滞，不替代同预算主比较。

## 5. 小中规模最优差距

仅当独立枚举完成或经过一致性审查的完整域 MIP 达到声明的数值容差，才写出该诊断实例的 J*。同时注明是枚举证明还是求解器数值认证。

未完成时保留 \(L\le J^*\le U\)。报告 \((U-L)/U\) 时称为“尚未排除的改善区间比例”，不预测实际可获得收益。当前路径与最优值之差优先用 \((J-J^*)/J^*\) 报告，并单独列绝对差。

完整域、固定前缀、空间走廊、小粒子子集与短时域实例是不同问题，必须分别标记。受限子问题的 dual 不得与原完整场景的可行 U 拼接成全局证书。

## 6. 收到结果后的行动表

| 观察 | 下一步 |
| --- | --- |
| B5 通过 Q | 固定胜出实现，围绕有效非局部操作做少量消融；设计独立档案验证 |
| B5 通过 T | 保留统一评分与数据，验证不同实例的同质量效率；不要通过改变语言／线程混入新因素 |
| 仅 B30 或少量 seed 有严格参考改善 | 保留改善见证；按固定规则做有限 300 秒诊断，尚不宣称稳定工程收益 |
| 在结构例上胜出，真实档案没有收益 | 检查实际档案是否具有相应结构，不筛选只对新法有利的真实场景 |
| 多个可证实例的 baseline 差距很小 | 这些实例不适合期待大幅提分；评估速度、可认证性或明确的新任务约束 |
| 新方法无改善、全局界仍宽 | 保留“尚未找到收益、全局差距未知”，结束本轮，不无限扩参数 |
| 发现路径／评分／整数模型错误 | 停止正式测量，保留失败；修复后新版本、新目录、新验证与冻结 |

## 7. 不应得到的结论

- “旧 STDC 不值得继续微调”不等于“所有含 STDC 的算法都无价值”。
- “多个优化器没有胜出”不等于“baseline 已证最优”。
- “更紧的连续松弛”不等于“可执行路线更好”。
- “不同 optimizer seed”不等于“不同目标运动实例”。
- “只在 Fundy 上改善”不能单独支持本批主要结论。
- “一个受限 MILP 的最优状态”不能认证完整真实问题。
