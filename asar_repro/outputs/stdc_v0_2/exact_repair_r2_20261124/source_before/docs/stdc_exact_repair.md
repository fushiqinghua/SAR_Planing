# STDC 独立受限精确修复：模型、证据与边界

该模块用于诊断既有 STDC 路径是否存在非局部改进，不改变原目标、评价器、forcing、冻结粒子归档或原搜索框架。求解一个受限模型，或在预算内没有找到改进，都不等于证明原问题全局最优。

## 1. 输入与时间约定

给定四连通、不可原地等待的矩形网格，固定起点和总移动步数 T。路径包括 v_0 至 v_T，共 T+1 个顶点。算法索引 t=0 对应冻结搜索归档的 CST 起始帧，尚未探测；首次探测发生在移动后的 t=1。这里不改写归档 UTC 时间，不重新执行事故到 CST 的漂移。

每个粒子 i 保持原 trajectory_id，归档给出绝对时刻的 cell_ids[t,i]。其初始未探测联合质量为 p_i，总质量为 1。域外、水陆及其他特殊 bin 不对应合法搜索顶点，不能被搜索动作检测，质量仍进入目标和最终 Pd。

原目标保持为

\[
J=\sum_{t=1}^{T} M_t,\qquad M_t=\sum_i b_{i,t},\qquad Pd_T=1-M_T.
\]

Pd 是独立报告指标，不加入目标或可行性条件；严格更小 J 才替换已有完整路径。

## 2. 修复邻域

选定 prefix_depth=a，固定原路径 v_0,...,v_a。剩余 t=a+1,...,T 共同优化，终点 v_T 自由，不要求回到原终点。

corridor_radius=r 时，允许空间区域是距原后缀 v_a,...,v_T 任一顶点的 Manhattan 距离不超过 r 的并集；不是逐时刻锁定在原 v_t 周围。每个时刻再与从固定前缀终点 v_a 出发的精确步数可达集相交。r=None 允许整个可达空间。原 incumbent 必须始终在所建邻域内。

“精确步数可达”包含距离和二分网格奇偶条件。首个自由层必须与 v_a 相邻；不得引入等待、自环、对角线或瞬移。图的邻接约束会排除因走廊删点而失去实际连接的候选。

## 3. 共享路线的位置变量

对每个自由时刻 t 和允许顶点 v，引入 x_{t,v}∈{0,1}：

\[
\sum_v x_{t,v}=1,
\quad x_{t,v}\leq\sum_{u\in N(v)}x_{t-1,u}.
\]

首层的上一位置是固定 v_a。每层唯一位置与上述邻接不等式共同保证一条连续的合法路线；所有粒子共享同一组 x。无需为每个粒子分别规划路线，因而保留单粒子 DP 松弛所忽略的共同路线约束。

## 4. 前缀评分与精确分组

用原 score_path 重放原路径，取得前缀累计 g_a 和原 ID 顺序后验 b_{i,a}。未来 cell_ids[a+1:T+1,i] 完全一致的粒子，可以在这个固定前缀子问题中分为同一组 k，权重为 β_k=Σ_{i∈k}b_{i,a}。

这不是按 (depth,vertex) 合并搜索状态。固定同一个前缀之后，同组粒子未来受到任意共享路径的检测乘子完全相同，因此后验总质量在每一步始终等于 β_k 乘同一个残余比例。不同粒子的前缀检测历史允许不同，必须先计算 b_{i,a} 再聚合，不能直接聚合原 p_i。

β_k=0 的组可以省去。特殊 bin 或未来不可被探测的正质量组不能丢失；即便其残余质量永远恒定，也应按剩余步数计入目标。完整路径最终仍须按原粒子 ID 和原评价器重放。

## 5. 归一化残余质量的精确二元线性化

对每组定义 r_{k,a}=1，0≤r_{k,t}≤1，实际质量为 β_k r_{k,t}。若该组在时刻 t 位于合法单元 c_k(t)，定义

\[
z_{k,t}=r_{k,t-1}x_{t,c_k(t)},
\qquad r_{k,t}=r_{k,t-1}-q_{c_k(t)}z_{k,t}.
\]

因 x 是二元变量，下列约束精确描述乘积：

\[
0\leq z\leq r_{prev},\quad z\leq x,\quad z\geq r_{prev}+x-1.
\]

若组位于特殊 bin 或该时刻其单元不在允许位置集合内，则 x=0，r_t=r_{t-1}。q=0 与 q=1 均无需除法并保持有效。归一化使质量较小的粒子不导致乘积变量本身过小；目标系数仍为真实 β_k。

实现仅为该组可能被检测、且 q>0 的事件时刻创建残余变量。首次事件之前的每个时间步按 β_k 计入常数；事件时刻 t 的残余 r 乘“下个事件时刻减 t”，若为末事件则乘 T+1−t。没有事件的组以 Hβ_k 进入常数，其中 H=T−a。这样省略没有检测机会的中间层变量，但没有省略目标中的任何 M_t。

首事件的输入残余固定为1，因此直接用 r=1−qx，不创建多余乘积变量；后续事件才使用上面的 z 线性化。位置二元变量仍覆盖每一步，事件压缩不会让搜救路径跳过时间或空间约束。

受限模型的完整目标是

\[
g_a+\sum_{t=a+1}^{T}\sum_k\beta_k r_{k,t}.
\]

若向求解器只传后缀目标，返回 primal 和 dual 时都必须加回常数 g_a；否则会把条件后缀值与完整 J 混淆。

## 6. 数值和结果验收

MILP 的精确性指整数模型与离散粒子模型的等价性，不指 Float64 求解器提供形式化证明。求解器返回 optimal 只表示它在该受限模型、求解器可行性和最优性容差下正常完成。调用者设置非零 mip_rel_gap 时，completed 也只表示达到该相对 gap 条件，应同时报告实际 restricted_gap。

当前实现检查位置整数误差及模型约束违反量不超过1e-7，随后对 solver fun、模型目标与原评分的差异执行独立1e-10检查。整数/线性约束公差没有替代原评分门槛。若原生求解器容差造成超过1e-10的重放差，返回 blocked/model_replay_mismatch；不将数值漂移当成改善。

为避免默认原生数值容差比原评分门槛粗，求解器设置 mip_abs_gap=0、mip_feasibility_tolerance=1e-10、primal_feasibility_tolerance=1e-10、dual_feasibility_tolerance=1e-10、small_matrix_value=1e-12。线程数固定为1、random_seed固定为0。SciPy 将部分原生选项透传给 HiGHS 时产生的 warning 保存在结果 stats，而不是消失或作为求解失败隐藏。输入档案生成 seed 与求解器 random_seed 是不同口径，分别记录。

任何候选都必须检查二元位置、每层唯一、前缀、四连通和总长度，再用原 score_path 重放 J/Pd。求解器连续残余质量及 objective 与原重放的不一致不能被掩盖；应记录误差及失败状态。未验证、非整数、非法或数值不一致候选不能替换 incumbent。

已有 incumbent 是独立可行上界，即便求解器超时未返回路径也不能丢失。仅在原重放 J 严格减小后接受新路径；相同 J 的 Pd 变化不作为新增次级目标。多个 J 最优路径可能有不同 Pd，Oracle 比较不能要求 Pd 唯一。

restricted_lower_bound 和 restricted_gap 只针对固定前缀及当前走廊的子问题。受限最小值可能大于全问题最小值，故受限 dual 不能拿来给全问题认证。理论上完全释放 a=0、无走廊且模型求解完成才覆盖原离散可行域，但本模块仍不把普通浮点求解状态提升为全局 ε 认证；theory_certified 保持 false。

## 7. 预算与可复现诊断

总方法时间应包含前缀重放、分组、建模、求解和最终重放。传给求解器的 time_limit 是建模后的剩余时间，不可重新获得完整额度。预算检查是合作式的，原生调用和最终核验可能产生超时余量，必须记录实际耗时及中止原因。

node_limit=0 在调用求解器前明确返回预算中止并保留初始路径，避免本地 SciPy 1.17 对 HiGHS 零节点 solution-limit 的通用错误码映射造成误报。正常 solver error 仍为 blocked，不与普通预算中止混同。

本地正节点额度也可能返回 SciPy status=4、原生 HiGHS Status 16: Solution limit reached。仅在调用者明确设置 node_limit 且这两个原生消息同时匹配时，才将其识别为预算中止，并保留原始 status/message 和映射说明。任意其他 status=4 不因此被宽泛视为正常结束。

模型估计/托管数组内存上限与整个求解器进程 RSS 不是同一概念。SciPy/HiGHS 的原生工作空间、稀疏矩阵转换和分支树可能额外占用内存；若需要硬进程内存上限，应由独立 worker 的父进程监控并明确记录终止，不能只凭模型数组估计宣称 RSS 已受限。

每个真实场景先核验原粒子/metadata/forcing SHA，再按预冻结的前缀和走廊顺序诊断，总探索时间与正式 5 秒性能实验分开。日志至少包括：输入指纹、seed、命令、stdout/stderr、模型规模、估计及实测内存、建模/求解/重放时间、求解状态、受限上下界、incumbent 来源、完整路径和原评价器 J/Pd。

MILP 节点是求解器子问题节点，不能与 A* 路径扩展数等同。诊断阶段获得的好路径也不能免费注入随后同预算比赛。

## 8. 如何解释结果

- 发现原评价器重放后严格更小 J 的合法路线：证明原 STDC 路径不是该离散模型的全局最优，并提供搜索策略遗漏改进的具体见证。
- 受限求解正常完成且无改善：仅支持当前前缀/走廊邻域内无更好路线，不能推广到其他前缀或整个空间。
- 预算中止且无改善：当前结论未知，记录可行 incumbent 和可用的受限下界。
- 任何模型、历史测试、原评分或可采纳断言失败：停止后续正式实验并记录 blocked，不能放宽验收条件。

Bay of Fundy 始终保留 physical_direction_unverified=true；不把使用官方 angle 的接入解释为物理方向已验证。所有场景沿用原评价器及既有 all-water 碰撞近似，不修改环境 forcing。
